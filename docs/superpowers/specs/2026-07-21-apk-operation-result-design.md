# APK 安装与文件推送常驻结果设计

## 目标

APK 安装和文件推送完成后，除保留现有短时提示外，在各自操作区域下方常驻显示本次操作结果，避免用户错过提示。

## 方案

- `App.jsx` 按设备分别保存安装结果和推送结果，结果包含 `status` 与 `message`。
- 操作开始时清除上一次同类结果，由已有加载状态显示“安装中”或“推送中”。
- 操作结束后显示“安装成功”“推送成功”，失败时显示“安装失败：原因”或“推送失败：原因”。
- `DeviceCard.jsx` 只负责把当前设备的结果传给 `PackageManagerPanel.jsx`。
- `PackageManagerPanel.jsx` 在安装行和推送行下方分别渲染紧凑状态条：进行中使用蓝色，成功使用绿色，失败使用红色。

结果在当前应用会话中保留，再次执行同类操作时覆盖；不写入本地存储。现有 toast 行为不变，Electron IPC 和 ADB 后端无需修改。

## 影响范围

- `src/App.jsx`
- `src/components/DeviceCard.jsx`
- `src/components/PackageManagerPanel.jsx`

不修改旧版 APK 管理面板、ADB 返回协议、OTA 或其他包管理操作。

## 验收标准

1. 安装执行期间显示“APK 安装中”，成功后常驻显示“安装成功”。
2. 安装失败后常驻显示“安装失败”及简短原因。
3. 推送执行期间显示“文件推送中”，成功后常驻显示“推送成功”。
4. 推送失败后常驻显示“推送失败”及简短原因。
5. 安装和推送结果互不覆盖，并按设备隔离。
6. 再次执行同类操作时旧结果先被进行中状态替换，结束后显示新结果。
7. 原有 toast、按钮禁用与加载动画保持不变。
